History UI

The chosen design in detail: History as a third home tab, a search box that follows the active tab, label rename, custom right-click menu, themed tooltip, and what opening a run looks like. In the first frame, right-click any row for the real custom menu, hover the pencil, status chip or gear for the tooltip, and double-click a title to rename it.

1. The History tab

2. Opening a run

Clicking a row loads that run's request into the editor as unsaved changes and shows its response. Undo all (next to Save) goes back to the latest saved version. An unsaved run opens as a draft.

3. Menus, tooltip and dialogs

All of these replace what the browser would show. Right-clicking anywhere else shows nothing.
